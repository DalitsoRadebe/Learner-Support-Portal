Register Page

As a learner, I want to create an account using my name, email address and password, so that I can access the Learner Support Portal.

1.I can enter my full name.

2.I can enter a valid email address.
3.I can create a password.
4.I can confirm my password.
5.The system validates my registration details.
6.The system displays an appropriate error message when my information is invalid.
7.I receive feedback when my registration is successful.

Login Page

As a registered learner, I want to log in using my email and password, so that I can securely access my learning information.

1.I can enter my email address.
2.I can enter my password.
3.The system validates my login details.
4.I receive an appropriate error message when my credentials are invalid.
5.After a successful login, I am taken to the Dashboard.

Recover Password

As a learner, I want to recover my forgotten password, so that I can regain access to my account.

1.I can select "Forgot password?"
2.I can provide my email address.
3.I receive appropriate feedback about my password-reset request.

Dashboard

As a learner, I want to see a dashboard summarising my learning activity, so that I can quickly understand my current progress.

1.I can see my name on the dashboard.
2.I can see my total number of tasks.
3.I can see my completed tasks.
4.I can see my outstanding tasks.
5.I can see my overall progress percentage.
6.I can see my upcoming tasks.
7.I can navigate to other sections of the portal.

Task Management

As a learner, I want to create a learning task, so that I can keep track of the work I need to complete.

1.I can select "Add Task".
2.I can enter a task title.
3.I can select a category.
4.I can select a due date.
5.I can select a priority.
6.I must complete all required fields before saving.
7.My task is added to the task list after I save it.

Update Task

As a learner, I want to edit or mark a task as complete, so that my task list accurately reflects my current work.

1.I can select "Edit".
2.I can change my task information.
3.I can mark my task as complete.
4.My updated information is reflected in the task list.
5.My progress information is updated when my task status changes.

Delete Task

As a learner, I want to delete a task, so that I can remove tasks that I no longer need.

1.I can select "Delete".
2.The system displays a confirmation dialog before deleting the task.
3.I can cancel the deletion.
4.I can confirm the deletion.
5.My task is removed only after I confirm the deletion.

Search Tasks

As a learner, I want to search for tasks, so that I can quickly find specific work.

1.I can enter search text.
2.My task list is filtered according to my search.
3.Relevant matching tasks are displayed.
4.I receive suitable feedback when no tasks match my search.

Filter Tasks

As a learner, I want to filter my tasks, so that I can focus on specific types or statuses of work.

1.I can select a task filter.
2.My task list updates according to the selected filter.
3.I can return to viewing all my tasks.

Sort Tasks

As a learner, I want to sort my tasks, so that I can organise my workload in a useful order.

1.I can select a sorting option.
2.I can sort my tasks by relevant information such as due date or priority.
3.The displayed order of my tasks updates according to the selected option.

Book Support Session

As a learner, I want to book a support session, so that I can receive assistance with topics I am struggling with.

1.I can select a support topic.
2.I can select my preferred date.
3.I can enter notes about the support I require.
4.The system validates all required information.
5.I can submit my support booking.
6.I receive a confirmation message after successfully submitting my booking.

Validate Support Booking

As a learner, I want my support booking form to provide validation feedback, so that I know what information I need to correct before submitting it.

1.I cannot submit the form when required fields are empty.
2.I receive an appropriate error message when I enter invalid information.
3.I can correct invalid information.
4.I receive clear confirmation feedback after a successful submission.

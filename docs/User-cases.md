Register Page

As a learner, I want to create an account using my name, email address and password, so that I can access the Learner Support Portal.

I can enter my full name.
I can enter a valid email address.
I can create a password.
I can confirm my password.
The system validates my registration details.
The system displays an appropriate error message when my information is invalid.
I receive feedback when my registration is successful.

Login Page
As a registered learner, I want to log in using my email and password, so that I can securely access my learning information.

I can enter my email address.
I can enter my password.
The system validates my login details.
I receive an appropriate error message when my credentials are invalid.
After a successful login, I am taken to the Dashboard.

Recover Password
As a learner, I want to recover my forgotten password, so that I can regain access to my account.

I can select "Forgot password?"
I can provide my email address.
I receive appropriate feedback about my password-reset request.

Dashboard
As a learner, I want to see a dashboard summarising my learning activity, so that I can quickly understand my current progress.

I can see my name on the dashboard.
I can see my total number of tasks.
I can see my completed tasks.
I can see my outstanding tasks.
I can see my overall progress percentage.
I can see my upcoming tasks.
I can navigate to other sections of the portal.

Task Management
As a learner, I want to create a learning task, so that I can keep track of the work I need to complete.

I can select "Add Task".
I can enter a task title.
I can select a category.
I can select a due date.
I can select a priority.
I must complete all required fields before saving.
My task is added to the task list after I save it.

Update Task
As a learner, I want to edit or mark a task as complete, so that my task list accurately reflects my current work.

I can select "Edit".
I can change my task information.
I can mark my task as complete.
My updated information is reflected in the task list.
My progress information is updated when my task status changes.

Delete Task
As a learner, I want to delete a task, so that I can remove tasks that I no longer need.

I can select "Delete".
The system displays a confirmation dialog before deleting the task.
I can cancel the deletion.
I can confirm the deletion.
My task is removed only after I confirm the deletion.
Search Tasks

As a learner, I want to search for tasks, so that I can quickly find specific work.

I can enter search text.
My task list is filtered according to my search.
Relevant matching tasks are displayed.
I receive suitable feedback when no tasks match my search.

Filter Tasks
As a learner, I want to filter my tasks, so that I can focus on specific types or statuses of work.

I can select a task filter.
My task list updates according to the selected filter.
I can return to viewing all my tasks.

Sort Tasks
As a learner, I want to sort my tasks, so that I can organise my workload in a useful order.

I can select a sorting option.
I can sort my tasks by relevant information such as due date or priority.
The displayed order of my tasks updates according to the selected option.

Book Support Session
As a learner, I want to book a support session, so that I can receive assistance with topics I am struggling with.

I can select a support topic.
I can select my preferred date.
I can enter notes about the support I require.
The system validates all required information.
I can submit my support booking.
I receive a confirmation message after successfully submitting my booking.

Validate Support Booking
As a learner, I want my support booking form to provide validation feedback, so that I know what information I need to correct before submitting it.

I cannot submit the form when required fields are empty.
I receive an appropriate error message when I enter invalid information.
I can correct invalid information.
I receive clear confirmation feedback after a successful submission.

About Java Script
JavaScript was created by Brendan Eich in May 1995 while working at Netscape Communications Corporation. The language was developed in just 10 days to meet the need for a lightweight scripting language that could make web pages more interactive and dynamic

Timeline 
1995 - Brendan Eich created java script
1997 - ECMA Script was released 
2008 - The TC39 technical comittee splitted into two camps, leading to the development of ES5, which has ES4 features

Limitation

- JavaScript is interpreted differently by different browsers, which can lead to inconsistencies in how code is executed
-The DOM manipulation in JavaScript can be slow, affecting the rendering speed of web pages
- If an error occurs in JavaScript, it can stop the rendering of the entire website

Characteristics of Java script

- JavaScript code is executed line-by-line by the browser
-Variables do not require explicit type declarations
-Responds to user actions and system events asynchronously
